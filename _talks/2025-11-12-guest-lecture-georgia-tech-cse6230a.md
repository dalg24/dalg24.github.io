I was honored to serve as a guest lecturer for the third time in Georgia Tech's
High Performance Parallel Computing graduate course (CSE-6230-A). I provided
students with an introduction to Kokkos, demonstrating how this portability
ecosystem enables single-source C++ code to run efficiently across highly
diverse HPC architectures, including CPUs and GPUs.
